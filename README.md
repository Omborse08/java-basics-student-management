# Student Management System (Core Java)

This is a **console-based Student Management System** built while learning **Core Java fundamentals**.

The purpose of this project was **not** to build a production-ready backend, but to deeply understand how basic programming concepts work together in a real program.

## Why I built this
While learning Java, I wanted a project that forced me to:
- think in terms of logic instead of tutorials
- handle edge cases manually
- understand how CRUD operations actually work behind the scenes

This project went through multiple iterations and refactors as I learned better ways to write logic.

## Features
- Add a student
- View all students
- Search student by ID
- Update student details
- Delete a student
- Input validation (empty fields, duplicate IDs, invalid age)
- Menu-driven console interface

## Concepts practiced
- Java basics (variables, control statements)
- Methods and modular code
- Arrays and index management
- Loops and conditional logic
- Basic input validation
- Simple CRUD operations
- Debugging and refactoring

## Tech stack
- Java (Core Java)
- Console I/O (`Scanner`)

## Notes
- This project intentionally uses **arrays**, not `ArrayList` or databases, to strengthen fundamentals.
- It is part of my **learning journey**, not a final backend project.
- A cleaner **OOP-based version** of this project will be built next using classes and collections.

## What I learned
This project taught me that:
- writing correct logic matters more than writing fast code
- small bugs in index handling can break the entire program
- refactoring is a normal and necessary part of development

---

If you are reviewing this repository, please consider it as a **practice project focused on learning**, not a showcase of advanced backend development.
